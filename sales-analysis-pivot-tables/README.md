# Sales Analysis Using Excel Pivot Tables

## Project Overview
This project uses Microsoft Excel to analyze sales performance across different countries, years and customer segments using PivotTables.

## Dataset
The dataset contains 113,036 sales records and 18 columns, covering January 2011 to August 2016.

## Tools and Techniques
- Microsoft Excel
- PivotTables and filters
- Data aggregation and summarization
- Customer segmentation
- Sparklines for trend analysis

## Analysis Performed
1. **Country Sales Performance:** Compared revenue, cost and profit across six countries.
2. **Profit Trends:** Analyzed annual profit across countries from 2011 to 2016.
3. **Customer Segmentation:** Used age group and gender filters to explore customer profitability.

## Key Insights
- The United States recorded the highest revenue and profit.
- Australia was the second-highest revenue contributor.
- 2015 recorded the highest annual profit.
- Profitability varied across countries and years.

## Conclusion
This project demonstrates the use of Excel PivotTables to summarize sales data, identify trends and generate insights that support data-driven business decisions.
